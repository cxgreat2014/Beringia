# kexts/ (APSL-2.0)

XNU drivers for the hosted machine (M4 onward): `BeringiaPlatform` (IOPlatformExpert), `BeringiaCPU` (IOCPU),
`BeringiaDisk` (paravirtual block device), `BeringiaSMC` (DSMOS), `BeringiaFramebuffer` (the boot framebuffer);
later `BeringiaNet`, `BeringiaConsole`, `BeringiaInput`. See docs/architecture.md, section 7.
